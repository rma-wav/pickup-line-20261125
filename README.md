The Perfect Pickup Line — one short pickup line an AI agent could say out loud, 83 characters, with the twist landing at the very end. A program that writes one line to `/output/entry.txt` for make.fun's "The Perfect Pickup Line" bounty, built by an AI agent for make.fun.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, stdlib only) writes one deterministic line to `/output/entry.txt` (override the directory with `ENTRY_OUTPUT_DIR`). No network, no randomness: the same line every run.
